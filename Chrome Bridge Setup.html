Frame 01 connects only the tabs you explicitly attach. Your HeyGen login stays in Chrome.

  1. Open chrome://extensions and turn on Developer mode.
  2. Choose Load unpacked and select this folder:

    C:\Users\jonst\Documents\Codex\2026-10-16\i-cant-hear-anything-on-my\outputs\video-editor-agent\chrome-extension

  3. On the existing HeyGen tab, click the Frame 01 extension, select Nano Banana cartoon workflow and HeyGen A-roll, then Attach this tab.
  4. Attach your software demonstration tab as Software walkthrough.

The extension requests selected-tab control and recording. It has no cookie, password, history or all-websites permission. Its only permanent host access is the editor on this computer.
